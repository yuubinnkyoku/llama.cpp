# Hexagon / llama.cpp：夜間作業の追加規則

- 最初に最新の `continuations/c46/phase46-handover-1tensor-integration.md` と現行コードを確認。資料と実装が異なる場合は実装・実測を優先して差分を残す。
- メインworktreeの未コミット作業を保護。隔離worktreeで小さくコミットし、**push・merge・破壊的Git操作はしない**。`GGML_HEXAGON_SPLIT=0` の従来経路を守る。
- 対象は `blk.0.ffn_up.weight` **1テンソルのみ**。数値一致、2ステップ連続、非同期の正当性、メモリ安全性が揃うまで対象を増やさない。
- 実測済みのIQ2_SはHTP用の独立 `WEIGHTS` テンソルへ元GGUFから設定する。タイル化済み重みの行ビュー・線形コピーは不可。CPU参照の完全一致、HTP参照とのビット一致、全行有限、センチネル0を検証する。
- 既知の正常試験条件は `GGML_HEXAGON_DMA64=0`、`GGML_HEXAGON_OPPOLL=0`。DMA64有効時の `0x2e` は再現済み。`flush_pending()`を無条件再試行でごまかさない。
- **メモリ削減は事前許可済み。** `P20_EARLY_SOURCE_RELEASE=0` は初期試験条件であって恒久禁止ではない。CPU担当行が独立した有効なprivate copyであり、元mmapへの参照が残らないと検証できた場合、`=1`を自律的に試してよい。参照が残るページ・共有ページは保護し、変更後に読み戻し・数値・2ステップを再検証する。安全性を証明できなければ有効化しない。
- **安全ガードは解除しない。** 試験ごと180秒以内、Swap-out増分1024 MiB到達、DSP異常、OOM兆候、強い熱制限では当該試験を停止する。原因調査と安全な条件変更は継続可。Android温度保護・ZRAM・重要サービスには介入しない。
- ADBがTCP接続だけなら**端末再起動は禁止**。接続が失われたらホスト側作業に切り替え、接続が戻らず実機以外に進めることがなくなった場合だけBLOCKED。
- 非同期投入の戻りや未回収キューだけでDSP演算の重なりを断定しない。実行中のDSP出力は読まない。同期後に境界行と全出力を比較する。DSP個別時刻がなければ実際の演算重複は未確定と記録する。
- 27Bの速度比較は正当性確認後。同一周波数・温度条件を優先し、CPU基準493.80 ms/tokenを参考にする。メモリガードに達した試験を性能合格として扱わない。
